# Agent Behavioral Rules

## Project Rule: 100% Free AI Models Only
- NEVER use paid versions or paid slugs of any AI model (Gemini, Groq, OpenRouter).
- For OpenRouter, ALWAYS use `openrouter/free` or explicit `:free` model slugs:
  - `openrouter/free`
  - `nvidia/nemotron-3.5-lightning:free`
  - `dots-studio/dots-3-note-preview:free`
  - `meta-llama/llama-3.3-70b-instruct:free`
  - `meta-llama/llama-3.1-8b-instruct:free`
- For Groq, use free models: `openai/gpt-oss-20b`, `openai/gpt-oss-120b`, `qwen/qwen3.6-27b`, `groq/compound`.
- For Gemini, use free models: `gemini-3.5-flash-lite`, `gemini-3.1-flash-lite`, `gemini-3.7-flash`.
- For Cerebras, use free models: `gpt-oss-120b`, `gemma-4-31b`.
